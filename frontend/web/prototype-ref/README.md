## 文件说明

| 文件 | 版本 | 说明 |
|---|---|---|
| `knowledge-base.v1-full.js` | v1（3.58MB） | 首轮下载版。含 **3 个案例页**（维修手册复核案例 / 备件管理案例 / 维修管理案例）及全部页面组件 |

## 版本差异

- **v1** 菜单：业务场景含 9 个子菜单（含 3 个案例页）+ 系统管理/运维监控
- **v2** 菜单：新增「AI 维修助手」「问答历史」；业务场景仅 6 个 Agent 页（备件精准查询 / 备件合规比对 / 采购辅助生成 / 备件台账导出 / 维修流程指引 / 维修资源清单）；知识库为 文档中心/复核任务/文档查看器；零件库为 零件管理/数据维护配置

## 提取要点（复刻参考）

- 页面组件均为 `const XxxPage = () => {...}`，可用 `IndexOf("const XxxPage")` 定位
- 6 个业务场景页使用统一 `CapabilityChatShell` + `ChatMessage` 架构
- 3 个案例页（v1）为「客户说明型」：业务流程图/泳道图/用例图/领域类图/数据流转图 + 案例数据示例
